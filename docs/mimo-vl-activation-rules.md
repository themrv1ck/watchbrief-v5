# MiMo-VL 画面证据开启规则

适用范围：WatchBefore 的单视频和列表任务。MiMo-VL 是补充画面事实的证据层，不代替字幕、MiMo ASR、内容提炼或审阅。**默认是逐条自动判定**，同时保留强制开启和强制关闭。

## 一、三档开关

1. **自动（默认）：** 每条视频的字幕或转写通过质量门槛后，只检查转写正文中的画面依赖线索。命中下述条件时才下载完整视频并加载 MiMo-VL；否则该条走纯文字链路。
2. **强制开启：** CLI `--visual-analysis` 或 WebUI 选择“强制开启”。列表的每条视频都分析画面，不受自动模式的时长上限或线索阈值限制，但仍须通过转写质量门槛。
3. **强制关闭：** CLI `--no-visual-analysis` 或 WebUI 选择“关闭”。即使正文有画面线索也不启动视觉链。

## 二、自动开启的确定性条件

同时满足以下条件才开启，判定结果和理由写入每条 `item_manifest.json` 的 `visual_activation`：

- 字幕或 MiMo ASR 的结果已通过 `transcript_quality`，且视频总时长已知、不超过 **30 分钟**，按当前抽帧间隔估计不超过 **181 帧**。默认 10 秒间隔对应约 30 分钟；若手动缩短间隔，自动档的可用时长也随帧数预算缩短。超过预算时跳过；仍可强制开启。
- 转写正文中至少有 **两个不同片段**含画面线索，并命中至少 **两类线索**，其中至少一类是“屏幕/图表指向”或“演示/效果对比”。线索类别见下表。
- 不读取标题、作者、频道或平台类型作为开启证据；“无字幕”本身也不触发。标题可用于报告显示，不能单独决定是否运行视觉模型。

| 线索类别 | 典型转写表述 | 画面可能补充的内容 |
| --- | --- | --- |
| 屏幕/图表指向 | “屏幕上”“界面”“画面中”“图表”“这张幻灯片” | 界面状态、图表轴、屏幕文字 |
| 操作步骤 | “点击”“拖动”“滑动”“打开菜单”“调整参数” | 实际操作路径和结果 |
| 演示/效果对比 | “前后对比”“实机演示”“展示效果” | 变化是否在画面中可见 |
| 影像形式 | “构图”“运镜”“镜头语言”“光影”“调色效果” | 可见的镜头和色彩变化 |

因此，软件教程、图表讲解、调色或影像分析可以逐条自动开启；纯口播、访谈和仅提到单个视觉词的视频通常保持关闭。线索不足时不能用标题猜测，相关漏判可用强制开启处理。

## 三、执行前门槛

- **证据门槛：** 当前正式链路仍须取得通过 transcript quality gate 的字幕或音频转写。MiMo-VL 不能绕过低覆盖率、时长缺失或错误字幕的拦截。完全无旁白的视频可能先失败；自动视觉模式目前不是视觉主导报告。
- **来源门槛：** 能按现有下载链取得目标视频画面。列表中的每个视频都要独立验证；不能把某一条的画面当成另一条的证据。
- **环境门槛：** 现有预检必须通过 Apple Silicon、BF16 四分片文件名与大小、`mlx-vlm==0.5.0` 和所需工具。还应核对模型安装来源对应官方 revision；当前预检只回报预期 revision 常量，尚不能单凭它证明本地文件的 revision 身份。约 32 GB 统一内存是运行建议，不是代码中的硬阈值；本机资源紧张时先处理单条视频，避免与其他本地模型重任务并发。

## 四、执行与失败边界

- 按完整视频时间轴确定性抽帧，包含首尾，默认相邻帧最多间隔 10 秒。模型只描述帧内直接可见的主体、动作、界面、图表和文字；时间戳、帧号、图片哈希由 WatchBefore 写入。
- 每条画面观察都保留时间戳、可见事实和不确定性。画面不能证明口播说了什么，也不能单凭画面证实视频中的医学、财务或其他外部事实。口播与画面冲突时分别标注证据来源和冲突。
- 视频获取、抽帧、模型输出、帧覆盖或证据哈希失败时，该条明确失败；批次 JSON 无效可拆小重试，单帧仍无效则失败。不得静默生成一份声称含有画面证据的纯转写报告。视觉证据哈希进入提炼、审阅和缓存身份，防止与纯转写报告混用。
- 自动模式按**每条视频**判定；强制开启和强制关闭对整个任务生效。视觉运行一旦选中，失败不能静默改为纯转写成功。

## 五、HTML 呈现边界

当前 renderer 会让画面证据影响内容总结和边界说明，但**尚未**独立展示“画面证据”栏目、逐帧图片或来源标签。开启 MiMo-VL 不等于 HTML 中能逐条核对画面观察。若今后增加展示，应只列与正文结论有关的观察，逐项给出“时间点、直接可见事实、不确定性”，并明确标记“画面所见”；不得把推测写成事实，也不得将全部抽帧原样堆进正文。实现该展示前，如需回读原始逐帧证据，应显式保留 debug 产物并核对其中的 `visual_evidence.json`；默认成功任务会清理临时 debug 目录。

## 六、当前可执行入口

```bash
cd "/Users/apple/Documents/New project/watchbrief_v5"
python3 scripts/watchbefore.py --source-url '<video_url>'
```

上面是自动模式。强制开启时加 `--visual-analysis`；强制关闭时加 `--no-visual-analysis`。WebUI 的“画面理解模式”提供相同三档选择。
