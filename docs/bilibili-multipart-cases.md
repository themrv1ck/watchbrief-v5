## 实际内容流程结果

**最终 12/12 完成，0 失败**。首轮为 11 成功 / 1 失败，P12 在本地 Qwen 的相邻时间区间校验中被拦下；同一后端单独重跑成功后更新总入口，原失败与重跑记录均保留。针对这类错误的重试反馈也新增了具体冲突节点及起止时间，不剪节点、不手改秒数。

12 个 CID、12 份转写哈希、12 个 cache key 均不重复。每份报告的时长等于 API 对应分 P 时长，链接选集参数与顺序一致，最终列表链接对应的 12 个文件均存在。最低转写覆盖率为 98.3%。

评分使用当前三维公式：信息密度 35% + 论据质量 35% + 话题兴趣 30%。各集参考报告保留视频总结版式。用户随后指出合集不连贯，总入口现已改为[合集连续阅读版](../templates/WATCHBEFORE_COLLECTION_RULES.md)：整套总结、四段内容主线、12 集连续内容和统一分集索引。生成的是诊断测试报告，未做浏览器视觉验收；跨集归纳基于已验证的真实分集内容，未重新采集或评分。

整套实跑中 P4 曾因旧的标题词匹配误报转入真实音频转写；因此该份已交付测试报告使用的是音频证据。随后保留同一份平台字幕，验证修复后的分集身份与覆盖门槛，可以避免今后这类不必要转写。其他质量门槛与未知身份字幕的原有拦截仍保留。

## 修复位置

- `scripts/resolver.py`：统一单集、整套与网页/API 回退的分集身份、标题、时长和规范 URL；区别独立 BV 合集；不完整列表明确失败。
