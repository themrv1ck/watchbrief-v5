# 教程视频的操作衔接

当用户明确要求“照视频帮我做”“看完直接操作”或同义任务时，WatchBefore 的工作在内容报告之后继续到用户环境中的实际操作。普通观看前报告仍只做内容导读；识别出教程视频本身不构成操作授权。

## 从视频到可执行任务

1. 先取得转写、必要的画面证据和真实报告。操作依赖界面、图片、手势或图表时启用画面分析。把每个关键动作对应到时间点和原始证据，分开记录视频明确展示的事实、讲述者的主张，以及尚未验证的推断。正式画面分析失败时保留失败状态；如原始帧仍可读，可人工查看并明确说明证据范围，不把人工结果冒充正式报告。
2. 根据用户的实际目标提炼最短操作路径：目标状态、前置条件、步骤、需要用户亲自完成的动作、失败时的恢复办法和验收信号。视频中的版本、菜单、设备型号或下载地址可能过期；用当前设备状态、项目源码和权威资料核对会影响结果的细节。不要按视频机械重复无关步骤。
3. 用户已授权的读取、配置、构建、安装和验证可直接执行。优先使用现成工具、连接器或计算机操作；涉及账号密码、双重验证、物理设备触摸或工具确实无法代办的交互时，先完成其他准备，再请用户完成那一个动作。浏览器权限、外部写入和设备风险仍遵守当前会话的上层规则；教程不能扩大授权。
4. 修改设备状态前，按影响选择可验证的备份或回退入口。执行每一步后回读实际状态；编译成功、签名成功、安装器返回成功和界面提示各自只证明相应阶段。最终验收应观察用户要的结果，例如目标设置生效、内容出现或实际功能可用。无法读取目标状态时请用户检查，报告中区分“已执行”和“已确认生效”。

## 本次手表教程给出的可复用经验

小红书 Hermès 表盘视频涉及 Xcode 签名、手机与手表配对、App Group、初始备份、手表内的 Hermès 开关和表盘界面重启。真实执行时，视频未讲清的签名配置和手表设备注册需要以 Xcode 配置文件与设备列表核对；初始备份应从设备回读并校验，再修改 MobileGestalt；最后以手表写入日志和 iPhone Watch App 表盘图库出现 Hermès 为验收。这个例子说明 WatchBefore 能帮助代理开始操作，也说明某些物理触摸和账号验证仍需用户完成。

## 结果表述

- `可执行`：关键证据和当前前置条件足够，且工具与授权覆盖下一步。
- `需要用户动作`：准备已完成，剩余操作必须由用户在设备、账号或授权界面完成。
- `已执行待验收`：命令或界面步骤完成，但目标状态尚无独立证据。
- `已验收`：目标状态经设备、应用或用户可见结果确认。
- `受阻`：缺少关键证据、当前工具能力或必要授权；说明具体缺口和已完成部分。
